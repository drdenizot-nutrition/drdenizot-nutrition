# Dr Denizot Nutrition

Custom code for the Dr Denizot Nutrition WordPress website.

## Architecture

WordPress core, plugins, uploads and database are managed by WordPress/Hostinger
and are not version-controlled here.

This repository contains the custom Astra child theme and other project-owned
code.

## Environments

- Production: https://drdenizot-nutrition.com
- Staging: https://staging.drdenizot-nutrition.com

## Deployment

The repository is deployed to the WordPress staging directory:

public_html/staging

Production deployment is performed only after staging validation.
